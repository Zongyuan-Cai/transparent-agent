# 设计决策

| 决策 | 理由与代价 |
| --- | --- |
| D01 文档先于实现 | 先确定契约，避免复制旧结构；独立设计提交 |
| D02 小 loop、完整 runtime | 上下文/资源/持久化在组装层，避免循环膨胀 |
| D03 原始传输+归一化 | 不丢未知字段/字节，增加本地存储 |
| D04 观察者容错、记录严格 | UI 失败不影响任务，记录失败不能暗中继续 |
| D05 模型截断、trace 全文 | 控 context 成本仍可检查；暂有内存成本 |
| D06 快照恢复、trace 追加 | 不重放副作用；暂不支持树/回滚 |
| D07 load_skill 按需 | 正文可见，支持用户目录资源且不放宽基础工具 |
| D08 串行、显式扩展 | 文件顺序/取消可预测，不自动执行项目代码 |
| D09 TUI 小改 | 先做记录与 inspect，界面不耦合核心迁移 |
