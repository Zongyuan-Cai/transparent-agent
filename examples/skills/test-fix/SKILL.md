# Fix a failing test

1. Read project instructions and identify the relevant test command.
2. Read the failing test and implementation, then reproduce the failure with bash.
3. Make a targeted change with edit. Use write for a new file or an intentional full replacement.
4. Run the relevant test again and inspect the exit code. Correct any remaining failure using the observed output.
5. Report the change, validation and remaining uncertainty. Claim success only when verified.

This skill does not execute scripts automatically or grant extra permissions.
